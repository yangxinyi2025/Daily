# PDF 课表教师与地点字段解析设计

## 目标

修复带文本层 PDF 课表中教师、地点因窄列换行而断裂、粘连或错位的问题。课程名称、星期、节次和周次的既有行为必须保持不变；导入后仅让低置信度字段在已有预览页中显式要求确认。

## 范围

- 仅处理现有 `PdfTimetableParser` 的 PDF 文本层与坐标布局输入。
- 仍优先使用 PDFBox 文本和坐标；不把有文本层的 PDF 转为图片，不新增 OCR、图片导入、网络调用或新依赖。
- 保留现有 Room 数据库、手工编辑、导入确认和课程存储模型。
- 不持久化用户修正别名；这属于后续独立需求。

## 解析架构

`PdfTimetableParser` 新增纯 Kotlin 的字段解析层，布局解析和纯文本回退解析均复用它：

1. 保留课程块原始文本，不能先按单行或普通空格拆字段。
2. 用标签边界截取：
   - 地点：`/场地:` 到 `/教师:`。
   - 教师：`/教师:` 到 `/教学班:`。
   - 校区：`/校区:` 到 `/场地:`。
3. 标签匹配允许中文/英文冒号与跨行内容，终止标签不吞入字段值。
4. 统一规范化字段值，再校验类型并在明显倒置时交换教师与地点。

标签区间优先于任何“像人名”或“像教室”的猜测。没有完整标签边界时，字段保持为空并标记为需要检查，绝不强行填入推测值。

## 规范化与校验

规范化只作用于已截取的字段：

- 统一全角标点、全角英数字和全角空格为半角。
- 删除字段内部无意义的空白、制表符和换行，因此 `俞\n彬` 变为 `俞彬`、`教三\n508` 变为 `教三508`。
- 保留连字符，故 `理1-\n403` 变为 `理1-403`。
- 地点校验识别教学楼/教室/实验室/校区/运动场/线上教学及常见编号样式。
- 教师校验接受 2–5 个中文字符，并拒绝地点关键词与教室编号样式。
- 仅当“教师像地点且地点像教师”时自动交换；否则保留解析值并产生字段警告。

## 课程段与去重

解析器不把同名课程视为唯一记录。每个含有节次/周次元数据的课程块都独立生成 `TimetablePreviewCourse`；教师、地点、周次不同的块必须保留为独立预览行。导入仓储继续接收这些独立行，不能以仅含课程名、星期和节次的键合并它们。

## 预览与置信度

不增加数据库字段。解析阶段为每行产生内存态字段警告：

- 高置信度标签字段：照常显示。
- 边界缺失、类型冲突或无法确认的教师/地点：当前预览行的对应输入框显示黄色提示，标题继续使用既有“需检查”状态。
- 用户可直接编辑地点、教师；编辑后沿用现有 `updateImportRow` 和校验流程。

这相当于本次的置信度呈现，不会持久化个人课表文本或修正历史。

## 测试

为纯字段解析器先写失败测试，再实现：

1. 教师跨行：`俞\n彬` → `俞彬`。
2. 地点跨行：`理1-\n403` → `理1-403`。
3. 教室编号跨行：`教三\n508` → `教三508`。
4. 非标准地点：`北校区足球场`。
5. 线上教学：`线上教学`。
6. 校内场地：`校内场地`。
7. 教师/地点明显倒置时自动交换。
8. 同课名、不同周次或教师时生成独立预览行。

保留既有合成 PDF 与文本回退测试，并运行完整 timetable 测试集与 Debug 编译。

## 不变量与验收

- 有文本层 PDF 只走 PDF 文本/坐标解析。
- 不删除用户手工修改能力。
- 不重构无关页面，不新增 OCR。
- 导入预览中，低置信度的教师或地点能够被识别并手改。
- 正常标签字段的跨行教师与地点准确分离，不出现跨课程或跨周次拼接。
