# 首页可爱风重构设计

## 目标与边界

将现有 Android 首页改为浅青绿、浅米白、胖圆吉祥物风，并尽量贴近交付包中的三张参考图。改动只覆盖首页的展示、首页内部状态切换、资源接入和共享底栏图标视觉。

保留真实的课程、待办、体重、经期数据来源，保留设置入口、一级导航路由、课表导入、日程编辑和健康记录业务。顶部入口不导航到课表、日程或健康一级页面，底栏在三种首页状态下始终保持首页选中。

## 状态与数据

在首页 UI 中保存 `HomeSection`，包含 `COURSE`、`CALENDAR`、`HEALTH` 三种状态，默认 `COURSE`。点击顶部课程、日历、健康入口只更新该状态。

`HomeViewModel` 继续组合课表、日程、健康和账单摘要。首页健康摘要扩展为同时提供最近体重、经期记录和预计下次经期，数据仍来自现有 `HealthDao`、`PeriodDao` 与经期周期偏好。不会写入或改变这些数据。

课程内容按真实今日课程列表展示序号、课程名、时间、地点；待办内容按真实今日待办列表展示序号、标题、时间。健康内容只展示最近体重和经期摘要。无数据时沿用既有业务含义，使用与新布局匹配的自然空文案。

## 视觉与组件

页面背景使用 `#F6F8E7`，主体与内容面使用 `#F9F7EE`，主要文字使用 `#204A0A`。强调色为紫色 `#B69DDB`、绿色 `#B1D685`、橙色 `#FFB246`。不引入明显渐变、玻璃拟态或新的大面积蓝色。

页面由以下区域组成：

1. 顶部 Header：固定“首页”和“今天的重点，一眼看清。”，保留设置入口，替换为软糖花外观。
2. 三入口与主体：低矮、宽胖的课程、日历、健康拱形入口与下方主体面板视觉连成整体。状态通过入口标签色和主体内容变化表达，不给选中拱形增加外描边。
3. 课程主体：标题“今日课程”与日期同行。课程采用轻分隔行，不套独立重阴影卡片；窄屏可换行但课程名、时间、地点保持清晰。
4. 待办主体：标题“今日待办”与日期同行。仅有序号、待办名、时间；不加新建按钮、优先级标签或额外图标。
5. 健康主体：两张并排大卡，只含今日体重和经期。经期卡使用橙色强调，体重无记录与经期未设置时保持已有空状态语义。
6. 底栏：保持五个既有入口与路由，替换为统一深墨绿、粗圆、可爱风图标；选中态为浅绿色圆润底座。

所有触控入口复用现有 Compose 点击语义；文字使用足够对比度和可自适应高度，装饰图片标记为无障碍装饰或赋予描述。

## 资源

从 `codex_homepage_redesign_bundle.zip` 导入提供的三只小羊图片和三张参考图。小羊作为首页可运行资源；参考图用于实现期间的视觉核对，不作为 UI 内容。图片保持比例，不拉伸、不裁掉书、日历或哑铃。

## 文件范围

- `feature/home/HomeScreen.kt`：新首页布局、三种主体内容和局部切换。
- `feature/home/HomeState.kt`、`HomeViewModel.kt`、`HomeSummaryRepositories.kt`：健康经期摘要与展示模型。
- `core/navigation/DailyNavHost.kt`：为首页摘要注入现有经期数据源。
- `core/designsystem/DailyBottomBar.kt` 与新增 drawable：底栏可爱风图标与选中态。
- `res/drawable-nodpi`：导入三只小羊资源。
- 首页单元测试：三种展示状态、内容行和健康空状态。

## 验证

运行首页相关单元测试和 Debug APK 构建。若本机有可用 Android 模拟器，再截取课程、日历、健康三种首页状态与参考图对比；没有可用模拟器时，交付 APK 供真机验收。
