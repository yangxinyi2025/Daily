# 首页日程地点与今日待办设计

## 目标

在日程编辑页提供独立、可选的“地点”字段。首页点击“日历”后仍停留在首页，并以现有“今日课程”时间线的视觉样式展示当天日程，标题为“今日待办”。每一项显示名称、地点和时间。

## 数据模型与兼容性

`ScheduleEvent`、`ScheduleEventEntity` 和 `ScheduleEditorState` 都新增可空地点值。输入框为空时保存为 `null`；已有日程在迁移后地点也为 `null`，不会丢失标题、时间、提醒或备注。

Room 数据库版本从 11 提升至 12。迁移 `MIGRATION_11_12` 仅向 `schedule_events` 增加可空 `location` 列，并加入数据库构建器。同步快照会读写 `location`；读取旧快照时该字段缺失应仍按 `null` 处理。

## 编辑与展示

日程编辑表单在“消息/备注”之前新增“地点（可选）”输入框。编辑已有日程时回填地点；保存后地点通过现有 Repository 映射持久化。

首页摘要 `HomeScheduleRow` 新增地点字段。`DaoScheduleSummaryRepository` 将当日日程的地点映射到摘要。`HomeSchedulePanel` 复用课程面板的容器、日期行、编号圆点、分隔线和地点/时间图标，仅把标题替换为“今日待办”。地点为空时显示“无”。没有当日日程时显示“今天还没有待办”。

## 验证

测试先覆盖：

- 日程首页内容保留名称、地点、时间；空地点展示为“无”。
- 编辑状态与模型/实体映射保留地点。
- 11→12 数据库迁移增加 `location` 且不删除已有日程数据。
- 快照序列化往返保留地点，并兼容缺少地点的旧快照。

随后运行相关单元测试和 Debug APK 编译，确认 Kotlin 编译、数据库迁移和打包都成功。
