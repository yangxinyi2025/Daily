# 移除账单与月预算设计

## 目标

从应用中永久移除账单功能及月预算设置。升级后的应用不再展示、读取、写入、备份或恢复账单与预算数据；设备中已有的这两类数据会在数据库升级时删除。

## 范围

- 删除账单底部导航项、路由、页面、导入、编辑、统计、分类和解析代码，以及专属测试、资源与样例文件。
- 移除首页的账单摘要、预算指标、对应数据流和跳转入口。
- 移除设置中的月预算输入、状态和 DataStore 偏好键。
- 移除交易、月预算相关 Room 实体、DAO、类型转换和依赖注入。
- 更新本地备份与同步快照：新快照不包含账单或预算；读取旧快照时忽略这些字段，继续恢复课程、日程、健康等保留数据。

## 数据删除与迁移

Room 数据库升级到新版本时执行专用迁移，删除 `transactions` 及月预算表。迁移不提供回滚或导出：这是用户明确要求的永久删除。

旧版备份的 JSON 中可能仍有 `transactions` 和 `defaultBudgetCents`。解码器将这些字段视为可选、废弃字段并丢弃；新版本导出的 JSON 不再写出它们。这保证旧备份不会因功能下线而阻止其他数据恢复。

## 界面与导航

底部导航只保留：首页、课表、日程、健康。首页不再显示账单摘要或预算；设置页不再显示预算分区。所有导航目的地、图标映射和可访问性测试同步删除账单项。

## 兼容性与边界

- 不更改课程、日程、健康、提醒、学期与 WebDAV 的既有功能。
- 不改变用户当前主工作区中未提交的 `HomeScreen.kt`；实现位于隔离分支，后续合并时再处理交叉修改。
- 不保留隐藏开关、空白页面或孤立数据表，避免未来误启用或持续占用维护成本。

## 验证

- 编译与导航测试确认账单目的地和底部导航项均不存在。
- 数据库迁移测试从现有版本升级，验证交易与月预算表被删除且其余表可用。
- 同步序列化测试验证新版不输出账单字段、旧快照仍可恢复保留数据。
- 运行关联的首页、设置、数据库、同步测试，并构建 Debug APK。
