# 日程页可爱风翻页日历设计

## 目标

在保留现有日程、节假日、调休、手动修正、日程创建与编辑能力的前提下，重构日程页主体为与首页一致的浅青绿、米白、深墨绿可爱风。页面主视觉是可翻页的桌面月历；底部导航保持现状，不在本次改动范围内。

## 范围

- 重构 `ScheduleMonthScreen` 的页面布局、月历视觉、日期状态卡和快捷创建区。
- 接入 ZIP 提供的小羊和快捷创建 PNG 素材。
- 将“浏览月份”和“选中日期”拆为独立状态。
- 实现前后方向不同的顶部装订轴翻页动画，并在动画期间禁用重复翻页。
- 保留既有日程详情、日期状态修正、普通创建、考试/生日/小事快捷创建和系统日历权限流程。

不包含：底部导航改造、日程数据表变更、节假日规则业务重写、生成新的图片资源。

## 状态与数据流

`ScheduleState` 增加 `visibleMonth: YearMonth`，初始值由当前 `selectedDate` 推导。`selectedDate` 继续表示用户真正选中的业务日期：点击日期才调用 `selectDate(date)`，并更新下方详情卡。

`ScheduleViewModel` 提供独立的月份浏览入口。浏览月份时只改变 `visibleMonth`，并刷新该月 6×7 网格需要的日历规则和当月日程查询范围；不改变 `selectedDate`。选择补位日期时保持现有语义：该日期成为选中日期，同时其月份成为可见月份。

界面层仅消费已准备好的当前月、前月和后月数据。动画期间不触发数据查询，也不更新 `visibleMonth`，直到动画结束后再提交月份状态，避免日历文字在纸页翻到一半时变化。

## 翻页日历

新增一个专注表现层的 `FlipCalendar` 组件，输入可见月份、相邻月份页面数据、选择回调和翻页意图。它不直接访问数据库或修改日程。

- 桌面月历使用浅米白纸页、浅绿色顶部页板、6–8 个绿色装订环和轻微后置纸页层。
- 右箭头：当前纸页以顶部中心为轴向上翻走，下一月纸页预先显示在下层。
- 左箭头：上一月纸页从顶部向下落回，覆盖当前纸页。
- 使用 280–380ms 的 `rotationX`/透视等效动画；若 Compose 的 `LocalMotionDurationScale` 表明用户减少动态效果，则替换为短淡入淡出。
- `isFlipping` 为真时禁用前后箭头；一次动画只接受一次月份变更。
- 月份计算使用 `YearMonth`，覆盖跨年、不同月长和闰年；日期网格继续沿用周一开始及 42 格补位逻辑。

## 页面结构

从上到下：

1. 标题“日程”、说明文案和保留原创建逻辑的圆形加号按钮。
2. 翻页日历，含月份标题、圆润箭头、星期栏、日期网格和“休 / 调 / 改”图例。
3. 日期状态卡，显示选中日期、工作日/休息日状态、来源、最近同步时间、现有“修正当前日期状态”入口；右侧使用 `mascot_schedule_clipboard.png`。
4. 同卡内的当日日程区域：无日程时显示现有 selectedDate 的空状态和“新建”；有日程时使用现有列表与编辑、删除入口。
5. 快捷创建区：闪电图标、普通新建入口、考试/生日/小事三个可点击胶囊按钮。

卡片遵循首页颜色：背景 `#F6F8E7`、表面 `#F9F7EE`、主文字 `#204A0A`、绿色 `#B1D685`、橙色 `#FFB246`、紫色 `#B69DDB`。不引入大面积蓝色、明显渐变或新的底部导航。

## 素材映射

- `mascot_schedule_clipboard.png`：日期状态卡右侧装饰。
- `icon_date_status.png`：当日日程区域图标。
- `icon_quick_lightning.png`：快捷创建标题图标。
- `icon_exam.png`、`icon_birthday.png`、`icon_minor_task.png`：对应三个快捷创建按钮。

素材复制为 Android drawable 资源并按原比例显示；不生成、覆盖或拉伸原始素材。

## 可访问性与性能

- 所有可点击的箭头、加号、新建和快捷创建按钮均提供中文可访问名称。
- 节假日、调休和手动修正保留文字标记，不只依赖颜色。
- 动态字体扩大时卡片和日程行可纵向增长。
- 月历只保留相邻三个月页面，规则和日程数据在动画前计算；大 PNG 通过资源 painter 复用。

## 验证

- 单元测试：月份前后切换、跨年、闰年、浏览月份不改变 selectedDate、选择补位日期、动画锁定、快捷创建入口和有/无日程展示。
- 保留并运行现有节假日/调休、日期修正、日程保存与提醒测试。
- 构建 Debug APK，并在模拟器截取日程页，与 `schedule_target.png` 对照顶部装订、月历层次、状态卡、快捷创建和小屏布局。
